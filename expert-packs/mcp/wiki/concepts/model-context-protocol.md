# Model Context Protocol

MCP (Model Context Protocol) è uno standard open-source progettato per collegare applicazioni AI a sistemi esterni. Consente a modelli come Claude o ChatGPT di interagire con fonti dati, strumenti eseguibili e workflow applicativi.

L'obiettivo è standardizzare il modo in cui un sistema AI ottiene contesto ed esegue operazioni esterne. Analogo a USB-C per l'hardware: un'interfaccia comune per collegare applicazioni AI a sistemi differenti.

## Funzioni abilitate

* leggere file locali
* interrogare database
* usare motori di ricerca
* eseguire calcoli
* invocare API
* utilizzare prompt specializzati

## Obiettivi principali

* standardizzazione delle integrazioni AI
* interoperabilità tra host e server
* separazione tra modello e sistemi esterni
* riuso di strumenti e workflow

## Punti chiave

* MCP è uno standard aperto per collegare AI e sistemi esterni.
* Introduce un'interfaccia uniforme tra host AI e servizi.
* Supporta dati, tool eseguibili e prompt riusabili.
